# ZCU111 动态 Outphasing 输能通信系统：近年论文对比与创新定位

检索时间：2026-08-15  
重点范围：2022–2025 年原始论文；同时保留两篇 2017/2020 年直接相关的先行工作，用于约束创新表述。

## 1. 系统对象与比较边界

本文拟研究的系统使用 ZCU111 RFSoC，以两路 DAC 分别驱动两套驱动放大器和功放，经非对称 Outphasing PA（OPA）及射频合路器连接同一副 2.4 GHz 输能天线。DAC 采样率为 5.89824 GSPS，DAC10 的采样镜像位于 3.49824 GHz，经双工器提取后用于通信。动态输能采用“距离前馈 + 目标端整流输出电压反馈”；DPD 则应使用 OPA 输出耦合的本地相干 RF 反馈。

当前工程已具备 DAC10/DAC11 同步 DBPSK、对称相位差和等幅 QMC 控制，但 README 所述物理验证仍是 DAC10 到 ADC10 的直连回环，尚未接入外置 OPA。因此，论文必须区分“已实现平台能力”和“接入 PA、双工器与目标端后的完整闭环实验”。

## 2. 近年关键工作

## 3. 最强的三个论文创新定位

### 创新 1：面向“目标端获得能量”的跨层闭环，而非只优化 PA 漏极效率

建立距离前馈与整流电压反馈的双自由度输能控制。距离估计用于快速给出初始功率区间，远端整流输出电压用于修正传播、姿态、负载和整流器非线性造成的模型误差。控制目标建议写为：

\[
\min_{m,A,\theta,D} P_{DC,TX}
\]

\[
\text{s.t.}\quad |V_{rect}-V^*|\le \epsilon_V,\quad
ACPR_{2.4}\le L_A,\quad EVM_{3.498}\le L_E,
\]

其中 \(m\) 为 PHASE/MIXED/BURST 模式，\(A\) 为共同或支路幅度，\(\theta\) 为 outphasing 角，\(D\) 为 Burst/PDM 占空比。

真正需要证明的优势是：在相同目标整流电压和动态距离轨迹下，发射端累计直流能耗更低、端到端效率更高，而不是仅在某个静态 OBO 点的漏极效率更高。

### 创新 2：OPA 工作点调度式 DPD与快慢双闭环

本地 OPA 输出耦合信号构成相干 RF 快环，用于估计非线性、支路失配、温漂和记忆效应；远端整流电压构成低速能量慢环。DPD 不用一个全局模型覆盖整个动态范围，而是按照 PHASE、MIXED、BURST 以及功率区间选择模型/系数，并在帧边界完成无扰切换。

需要强调：远端整流电压不能替代 DPD 训练反馈，因为它不包含相干幅相和带外失真信息；它只能调节外层输能工作点。

### 创新 3：DAC 镜像通信保持型联合预失真

DAC10 的数字波形同时决定 2.4 GHz 分量和 3.49824 GHz 镜像分量。若只以 2.4 GHz OPA 输出 NMSE/ACPR 为目标调整 DAC10，则可能改变镜像的幅相、EVM 和 BER。因此，本文可将镜像通信质量作为显式约束或多目标代价：

\[
J=w_1 NMSE_{2.4}+w_2 ACPR_{2.4}+w_3 EVM_{3.498}
  +w_4(V_{rect}-V^*)^2+w_5P_{DC,TX}.
\]

该点比“使用 DAC 镜像通信”本身更强：它揭示并解决了能量支路 DPD 与镜像通信之间的耦合问题。检索到的 OPA/DPD/WPT 论文通常只优化单个 RF 输出或单个应用目标，未给出这种双频质量约束。

## 4. 推荐的论文对比矩阵

| 方案 | OPA 高效回退 | 动态功率调节 | 本地相干 RF 反馈 | 远端整流反馈 | 模式调度 DPD | 镜像通信约束 | 端到端能效目标 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 非对称/混合模式 OPA 论文 | 是 | 多为静态扫描 | 实验测量 | 否 | 否 | 否 | 否 |
| 功率自适应 DPD | 非专门针对 OPA | 是 | 是 | 否 | 按功率自适应 | 否 | 否 |
| FPGA Chireix OPA + DPD | 是 | 幅相扫描 | 是 | 否 | 未面向 WPT 分段 | 否 | 否 |

## 5. 必须完成的消融实验

1. 开环相位控制，无 DPD。
2. 开环相位控制 + 单一全局 DPD。
3. 分段/工作点调度 DPD，但无远端整流反馈。
4. 仅远端整流电压闭环，但无本地 RF DPD。
5. 本地 RF 快环 + 远端电压慢环。
6. 第 5 项不约束 3.49824 GHz 通信质量。
7. 完整方案：双闭环 + 模式调度 DPD + 镜像通信约束。

此外，应分别比较 PHASE、MIXED、BURST 三种深回退策略；Burst 不能简单等同于关闭其中一条支路，因为这会破坏非对称 AB/C 子 PA 与 modified-Chireix 合路器的设计负载条件。Burst 应以某个已标定高效双支路 ON 工作点进行时间域占空比调节。

## 6. 建议报告的指标

- PA/射频：饱和和 0–12 dB OBO 的 DE/PAE、增益、AM-AM、AM-PM、NMSE、ACPR/ACLR、模式切换瞬态。
- 输能：目标整流电压 RMSE、阶跃超调、稳定时间、距离变化轨迹下的掉电率、接收 DC 功率、发射 DC 功耗和端到端效率。
- 通信：3.49824 GHz 输出功率、EVM、BER、频谱掩模、双工器隔离度以及调功/DPD切换时的误码突发。
- 实现：RFSoC PL 吞吐与时延、DSP/LUT/FF/BRAM、系数存储、训练时间、DPD 自身数字功耗。
- 鲁棒性：温度、供电、负载、天线姿态、距离估计误差和反馈丢包条件下的性能。

## 7. 可直接用于引言或摘要的谨慎表述

> 近年非对称及混合模式 Outphasing 研究已显著提高 8–12 dB 功率回退区间的效率，多输入 PA 的驱动轨迹优化与功率自适应 DPD 也已有实验基础；另一方面，闭环远场无线输能研究主要通过波形、波束和有限反馈提高接收直流功率。与这些分别面向功放效率、射频线性度或接收能量的工作不同，本文面向动态距离下的目标整流电压调节，在 RFSoC 上联合实现非对称 OPA 分段工作点控制、本地相干 RF 反馈 DPD 与远端整流电压反馈，并将 DAC10 的 3.49824 GHz 镜像通信质量纳入预失真约束，从而在满足能量与通信指标的同时降低发射端直流能耗。

不建议写“首次提出动态 DPD”“首次 FPGA 控制 Chireix OPA”或“回退效率最高”。更稳妥的创新结论是：

> 在所检索的相关原始论文中，尚未发现将非对称 OPA 的分段工作点调度、模式相关 DPD、本地 RF 快环、远端整流电压慢环及 DAC 镜像通信约束集成于同一 RFSoC 原型并进行端到端动态验证的工作。

“尚未发现”只代表本次检索结果；投稿前仍应按目标期刊数据库进行一次系统性复核。
